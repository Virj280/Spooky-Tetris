Testing plan for spooky tetris

1. Make sure bats appear at the right height
2. Make sure the block appears. And at the correct size
3. Make sure the block can fall with gravity
4. Make sure the block moves left/right upon pressing left/right arrow keys
5. Make sure the block stays within the boundaries
6. Make sure the block can stop falling when it hits the floor
7. Make sure another block appears when the first one hits the floor
8. Make sure the block has the right hitbox and can layer on top of each other properly
