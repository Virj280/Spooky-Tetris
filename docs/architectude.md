# Overview
Our game is a tetris mod that has bats flying around to serve as decoration

# Files
| File | Function |
| --- | --- |
| index.html | Running the game by using other files |
| style.css | Decoration |
| tetris.js | Holding code used to move tetrominoes and spawn bats; uses a lot of images and sounds |

# Other stuff
.pixil folder: storing pixil art
assets folder: png art and sounds

# How the game is played
Left and right arrows to move the tetromino, down arrow to drop the tetromino faster
When touching the ground, the tetrominoes stay there, and you can layer more tetrominoes on them 
Bats spawn as distractions
