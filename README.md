# Spooky-Tetris v1.0
Game link: [[virj280.github.io/Spooky-Tetris](url)]([url])

CS group project for a Halloween themed Tetris game. Assets like sprites and sfx can be found in /assets, and some sprite import files can be found in .pixil. The game itself holds all the original tetrominoes, as well as custom bats that trigger random events.

The game is tetris; you drop tetrominoes and you can move them around

Controls: left/right arrow to move, down arrow to force the block down, up arrow to rotate block

Uh once a row gets full, it is deleted and you are awarded points.

Also, skinny bat will appear, which is a harbinger of fat bat, which will spawn and obstruct you from placing blocks. Which is the whole point of this tetris mod.
Also, when you are playing the game, Ego Bat will insult you, and Loser Bat will insult you when you lose (and possibly close the tab).
